# 贴图封面：先选底图，再排文字

默认采用有完整画面感的原图铺满1080×1440画布。标题直接叠在画面上，上部用深色渐变保证阅读，下部保留主体、细节和层次。三页版与多页版共用这一原则。

## 选图

- 优先与主题直接相关、能独立撑起画面的实验照片、显微图、仪器或样品场景，以及研究机构/团队的官方主视觉。官方插画也可以，记录它的真实来源与性质。
- 选图时先看主体是否清楚、画面有无前后层次、上部是否能承载标题、竖向裁切后关键物体是否完整。分辨率足够不等于适合当封面。
- 密集论文流程图、表格、整页PDF和应用截图通常留在正文证据页。不要为了填充封面，直接把难读的论文页面放进白色卡框。
- 找不到适合满版裁切的素材时，继续找该主题的官方主视觉或其他有依据的原图；在审核记录中说明素材限制，不用无关漂亮图片或虚构实验图凑数。

## 构图

- 底图使用 `object-fit: cover` 铺满画布，保持原始比例。封面主图不带白色底框、圆角容器或内边距。
- 页眉与栏目/日期放上方，主标题一般两行，下面一句必要背景；正文页可继续使用白底证据图框。
- 标题直接压在画面上。上方渐变较深，中下部逐步变透，底端再适度压暗以承载图注与页码。不要把整张图一并压黑，也不要用不透明实色面板挡住画面。
- 用 cover 卡片的 `focal_point: {"x": 0.5, "y": 0.65}` 调整可见主体。值在0–1之间，映射到CSS `object-position`；宽图竖裁时尤其要检查人物、培养皿、仪器或显微主体是否被切掉。
- 图片允许作为封面进行编辑裁切，但不能借裁切更改数据含义。需要完整标签、比例尺和对照关系的证据图放到正文中完整呈现。
- 默认把标题和副标题收在画布上半部，留出中下部给主体。字太多时压缩文案，不恢复“上半部大色块、下半部白框截图”的版式。

## 交稿前看成图

1. 在原尺寸及手机缩略尺寸查看：第一眼能否看见主题相关主体，标题能否读清。
2. 核对背景确实满版、没有拉伸、裁切焦点正确，主体没有被文字遮住。
3. 查看首图的方形和横向封面裁切；必要时调整标题/焦点，保留用户已有的后台裁切设置。
4. 逐页确认其余证据页没有因封面CSS调整而变化。
